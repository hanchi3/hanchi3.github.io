建立数据模型

models/post.go：
Post -（VO），是一个表示业务实体（例如，数据库中的帖子）的对象。包含了帖子相关的基本属性，它主要用于表示帖子本身的核心业务值。与帖子的数据库表结构完全一致。

  • 解析字段标签：
  • json:"<json_key>"：
    json 标签指定字段在 JSON 编码/解码 时的行为，其中 <json_key> 是希望在 JSON 数据中使用的字段名。"-" 表示忽略该字段，即当你将结构体编码为 JSON 时，这个字段不会出现在结果中。同样，解码时也会忽略传入 JSON 中的该字段。
  • db:"update_time"：
    db 标签指定字段在数据库操作中使用的列名。这个标签通常用于与数据库进行交互时，帮助将结构体字段与数据库列映射起来。

ApiPostDetail -（VO），是用来表示单个帖子的详细信息的，将帖子的基本信息（来自 Post 结构体）和附加信息（如社区信息、作者名称、投票数等）组合在一起，供 API 响应使用。

Page -（VO），用于表示分页信息，包含了总记录数（Total）、当前页码（Page）以及每页大小（Size）。

ApiPostDetailRes -（VO），是 API 响应的主要载体，它将分页信息和帖子详情数据组织成一个统一的结构，以便于前端展示和传输。

📖 数组与切片
数组和切片的区别相同点 都只能存储一组相同类型。 都是通过下标来访问，并且有容量长度，长度通过 len 获取，容量通过 cap 获取。 在函数传递中，数组切片都是值传递。 区别 数组是定长，访问和复制不能超过数组定义的长度，否则就会下标越界；slice 即动态数组，是对数组的封装，其长度并不固定，我们可以向切片中追加元素，它会在容量不足时自动扩容。 数组是值类型，切片是引用类型，每个切片都引用了一个底层数组，切片本身不能存储任何数据，修改切片的时候修改的是底层数组中的数据。切片一旦扩容，指向一个新的底层数组，内存地址也就随之改变。 切片的底层结构数组就是一片连续的内存， slice 实际上是一个结构体，包含三个字段：长度、容量、指针。指针指向切片所引用的底层数组的首地址。切片是引用类型，多个切片可以共享同一个底层数组，因此对一个 slice 的元素进行操作是有可能影响到其他 slice 的。 123456// runtime/slice.gotype slice struct { array unsafe.Pointer // 元素指针 len int...
